# France — region directory

**Classification (broad→leaf):** Regional AOC → Sub-regional/District AOC → Communal/Village
AOC → Premier Cru → Grand Cru. Cru tiers exist mainly in Burgundy, Alsace, Champagne;
Bordeaux uses château-based classifications instead. **~363 wine AOC/AOP** total.
**Leaf level:** individual Grand Cru / named cru vineyards (Burgundy's 33 Grand Crus +
1,247 climats; Alsace's 51 Grand Cru lieux-dits) — drill here next.

The hierarchy is region-specific, so "leaf" and "mid tier" are defined per region. Table
lists the principal communal/sub-regional/cru appellations just above the leaf.
