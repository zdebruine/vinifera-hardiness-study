# Spain & Portugal — region directory

## Spain

**Classification (broad→leaf):** Vino / VT (IGP) → Vino de Calidad (VC) → DO → DOCa/DOQ;
plus single-estate **Vino de Pago (VP)**. **~69 DOs**, 2 DOCa/DOQ (Rioja, Priorat), ~25 Vino
de Pago. **Leaf level:** **Viñedo Singular** (single vineyard, e.g. Rioja since 2017) and
Vino de Pago; intermediate locality tiers Vino de Zona / Vino de Pueblo (Municipio).

have named **sub-regions**. **Leaf level:** the DOC sub-region (single-vineyard naming is
