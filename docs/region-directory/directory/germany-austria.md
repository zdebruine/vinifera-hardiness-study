# Germany & Austria — region directory

## Germany
**Classification:** **Anbaugebiet** (13) → **Bereich** (39) → Großlage → **Einzellage**
(~2,600, the leaf). The 2021 wine-law reform adds a Gebietswein → Ortswein → Lagenwein
origin pyramid (phasing to 2026); **VDP** overlays Gutswein → Ortswein → Erste Lage →
**Große Lage** (dry = Großes Gewächs/GG). Drill to Einzellage next.

## Austria
**Classification:** Weinbaugebiet ("Gebietswein") → Ort ("Ortswein") → **Ried** (single
vineyard, "Riedenwein", the leaf); since **2023** legal **Erste Lage** / **Große Lage** tiers
(first labels from 2025 vintage). **18 DACs.**
