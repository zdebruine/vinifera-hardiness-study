# Italy — region directory

**Classification (broad→leaf):** Vino → IGT/IGP → DOC → DOCG → (within top denominations)
sottozona / MGA / UGA. EU: DOC+DOCG = DOP; IGT = IGP. **~76–79 DOCG, ~330 DOC, ~118 IGT.**
**Leaf level:** single-vineyard **MGA/UGA** ("menzioni geografiche aggiuntive"), formalized
in a few denominations — **Barolo ~181 MGA**, **Barbaresco ~66 MGA**; UGA in Chianti
Classico; "contrade" informally on Etna. Drill here next where it exists, else sottozona.
